# Heart Failure Clinical Records — EDA & Machine Learning

A reproducible Python portfolio project for exploratory data analysis and binary classification of the Heart Failure Clinical Records dataset.

## Techniques
- Data validation and descriptive statistics
- EDA and visualisation
- Logistic Regression, Random Forest, Decision Tree, LDA and Perceptron
- Stratified train/test split and 5-fold cross-validation
- Accuracy, precision, recall, F1 and ROC-AUC
- Confusion matrices, ROC and Precision–Recall curves
- Hierarchical clustering

## Run
Place the dataset at `data/heart_failure_clinical_records_dataset.csv`, then run:

    pip install -r requirements.txt
    python main.py

Optional: `python main.py --show-plots`

Results are written to `outputs/`.

Educational/portfolio project only; it is not a clinical decision-making system.
